# Archived GitHub Actions

These scheduled workflows created dated branches inside this same repository. Git commit history already preserves those source revisions, so the duplicate cron backup has been retired under the repository owner's Actions cleanup plan.

`manifest.json` records exact source SHA, byte hashes, dependency/caller checks and restoration instructions. Existing backup branches and Actions history are preserved. Workflow files under this directory are archival data and are not GitHub Actions entrypoints.
